# domineering

Domineering（多米诺棋）——纯 Python 标准库实现的双人对弈小游戏。

## 玩法

- 8×8 棋盘，两人轮流放多米诺骨牌
- **竖方（V，先手）**：只能放**竖向**多米诺（占上下相邻两格）
- **横方（H，后手）**：只能放**横向**多米诺（占左右相邻两格）
- 轮到谁时**无子可放即判负**

## 用法

```bash
python3 -m domineering                 # 人机对战，你执竖方先手
python3 -m domineering --side h        # 你执横方后手，AI 先手
python3 -m domineering --auto --games 20 --seed 42   # AI 对 AI 自动演示
python3 -m domineering --auto --games 5 --verbose    # 逐局打印
```

走法输入示例：`d4 d5`（两个相邻格，字母列 + 数字行），输入 `q` 退出。

## AI 说明

贪心 AI：每步做 1 步前瞻，最大化（己方下一步合法走法数 − 对方下一步合法走法数），平局随机打破。`--seed` 保证可复现。

## 已知局限

- AI 只是 1 步前瞻贪心策略，不做深层搜索；熟悉棋理的人类大概率能赢
- 只有 8×8 标准规则，无其他棋盘尺寸/变体
- 无存档、无悔棋、无图形界面（文本棋盘）
- Python 3.10+
